This repository contains Scripts folder of my Universitys individual project. The screenshot and applied mechanics are available under this link: https://onlyplayy.itch.io/incarnation-the-couch-multiplayer-game.

My scope of work included:
- Designing the game, and modelling (with Blender) maps, characters and power ups.
- Programming character movement, skills, power ups and AI characters.
- Optimising the game for split-screen multiplayer gameplay.
- Design and implementation of UI/UX elements according to own idea and industry level quality.
